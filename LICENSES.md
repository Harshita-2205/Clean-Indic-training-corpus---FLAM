# Data source and attribution notes

## Hindi Wikipedia

- Source: Hindi Wikipedia current pages-articles XML dump, pinned snapshot 2026-10-01.
- Download: `https://dumps.wikimedia.org/hiwiki/20261001/hiwiki-20261001-pages-articles-multistream.xml.bz2`
- Text license: CC BY-SA 4.0 and GFDL options per Wikimedia terms. This project records the CC BY-SA 4.0 path. Attribution should link to each reused article where practical; modifications should be noted; share-alike applies to adapted material.
- Source-specific authorship/history remains with contributors listed in Wikipedia page history.
